# Apollo for Windows

Installers for **Apollo**, the habit tracker you own for life.

- **Download:** [Apollo-Setup.exe](https://github.com/apollohabit/apollo-releases/releases/latest/download/Apollo-Setup.exe)
- **Buy a licence key:** https://apollo-habits.pages.dev

Open the installer and Apollo installs in seconds. It updates itself from this page.

Windows may show "Windows protected your PC" the first time, because the installer isn't signed with a paid certificate. Click **More info → Run anyway**.

This repository holds the installers only.
